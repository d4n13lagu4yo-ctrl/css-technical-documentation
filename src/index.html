Introduction

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML.

CSS describes how elements should be rendered on screen, on paper, in speech, or on other media.

CSS is among the core languages of the open web and is standardized across browsers according to W3C specifications. Modern CSS is developed in modular fashion, with individual specifications advancing at their own pace rather than following versioned releases like CSS3.

This documentation covers fundamental and advanced CSS concepts, from basic syntax to modern layout techniques, helping you build well-styled, responsive web pages.

body { font-family: Arial, sans-serif; color: #333; background-color: #fff; }
CSS Selectors

Selectors are patterns used to select the HTML elements you want to style.

There are many types of selectors, each with different specificity and use cases.

h1 { color: blue; }
  • Type selectors (e.g., h1, p, div)
  • Class selectors (e.g., .my-class)
  • ID selectors (e.g., #my-id)
  • Attribute selectors (e.g., [type="text"])
  • Pseudo-class selectors (e.g., :hover, :focus)

Combinators allow you to combine multiple selectors to target elements based on their relationship in the document tree. The descendant combinator (space), child combinator (>), adjacent sibling combinator (+), and general sibling combinator (~) each express different relationship patterns.

/* Descendant: all p inside article */ article p { line-height: 1.6; } /* Child: direct children only */ ul > li { list-style: none; } /* Adjacent sibling: p immediately after h2 */ h2 + p { font-weight: bold; }
Box Model

The CSS box model is a fundamental concept that describes how elements are structured.

Every element is composed of content, padding, border, and margin areas.

Understanding the box model is essential for creating layouts.

box-sizing: border-box; margin: 10px 15px;

The box-sizing property controls how the total width and height of an element are calculated. The default value content-box adds padding and border to the specified dimensions, while border-box includes them within the specified width and height, making layout calculations more predictable.

Margins between adjacent block elements can collapse, meaning the larger margin value wins instead of adding them together. This behavior affects vertical margins and is important to understand when spacing elements.

  • Content: the inner area where text and images appear
  • Padding: space between content and border
  • Border: the edge surrounding the padding
  • Margin: space outside the border separating the element from others
Flexbox

Flexbox is a one-dimensional layout method for arranging items in rows or columns.

It provides powerful alignment and distribution capabilities.

display: flex;
  • justify-content controls horizontal alignment
  • align-items controls vertical alignment
  • flex-wrap allows items to wrap onto multiple lines
  • gap creates consistent spacing between flex items

The flex container properties (flex-direction, flex-wrap, justify-content, align-items, align-content) control the overall layout behavior, while flex item properties (flex-grow, flex-shrink, flex-basis, align-self, order) let individual items adjust their size and position within the container.

.container { display: flex; flex-direction: row; justify-content: space-between; align-items: center; gap: 1rem; }
Grid Layout

CSS Grid Layout is a two-dimensional layout system for the web.

Grid allows you to create complex layouts with rows and columns.

display: grid; grid-template-columns: 1fr 1fr;
  • Grid is ideal for page-level layouts
  • Grid items can be placed explicitly using line numbers or named areas
  • The fr unit distributes available space proportionally

Grid introduces powerful features like the fr unit for flexible track sizing, grid-template-areas for visual placement naming, and auto-fill/auto-fit for responsive layouts without media queries. The gap shorthand provides consistent spacing between both rows and columns.

.container { display: grid; grid-template-columns: repeat(3, 1fr); grid-template-rows: auto; gap: 1.5rem; } .header { grid-column: 1 / -1; }
CSS Syntax and Rules

CSS syntax is built around rulesets, also called rules. A ruleset consists of a selector and a declaration block. The selector specifies which HTML elements to target, and the declaration block contains one or more declarations enclosed in curly braces.

Each declaration pairs a property with a value, separated by a colon and terminated by a semicolon. Multiple declarations are stacked within the same block to define all the visual characteristics for the selected elements.

selector { property: value; property: value; }

At-rules are a special category of CSS statements that begin with an @ symbol. They extend CSS capabilities by controlling how styles are applied under specific conditions. Common at-rules include @media for responsive design, @keyframes for animations, @font-face for custom fonts, and @import for including external stylesheets.

CSS is whitespace-insensitive, meaning line breaks and spaces between tokens are generally ignored. However, proper indentation and formatting are essential for readability and maintainability, especially in projects with many rules.

  • Selectors target HTML elements
  • Declaration blocks contain property-value pairs
  • At-rules begin with @ and provide conditional or import behavior
  • Comments use /* */ syntax and can span multiple lines
Cascade and Specificity

The cascade is the algorithm that determines which CSS rules apply when multiple rules target the same element. It considers importance, specificity, source order, and origin to resolve conflicts and produce the final computed style.

Specificity is a weight system that browsers use to decide which property values are most relevant to an element. Each selector type carries a different weight: inline styles have the highest specificity, followed by IDs, classes and attributes, and finally type selectors.

/* Specificity: 0,0,0,1 (type) */ p { color: blue; } /* Specificity: 0,0,1,0 (class) */ .text { color: red; } /* Specificity: 0,1,0,0 (ID) */ #intro { color: green; }

The !important flag overrides normal specificity, but should be used sparingly as it makes debugging and maintenance more difficult. When !important is present, the rule with the highest specificity among those marked important wins.

  • Inline styles beat everything in normal flow
  • ID selectors beat class selectors
  • Class selectors beat type selectors
  • Source order breaks ties: later rules override earlier ones
  • !important reverses normal specificity but should be avoided
Colors and Backgrounds

CSS provides multiple ways to define colors, including named colors, hexadecimal notation, RGB/RGBA, HSL/HSLA, and the modern color() function. Each format offers different advantages for readability, precision, and color space support.

The background shorthand property sets all background properties at once: color, image, position, size, repeat, attachment, and clip. Backgrounds can be solid colors, gradient patterns, images, or combinations of multiple layers stacked on top of each other.

/* Named color */ color: crimson; /* Hexadecimal */ color: #ff6347; /* RGB with alpha */ color: rgba(255, 99, 71, 0.8); /* HSL with alpha */ color: hsla(0, 100%, 66%, 0.8);

Gradients are background images generated dynamically by the browser. Linear gradients transition along a straight line, radial gradients radiate from a center point, and conic gradients rotate around a central axis. Multiple gradients can be combined to create complex visual effects.

  • Hex colors are widely used and compact (#RRGGBB or #RGB)
  • RGBA adds an alpha channel for transparency control
  • HSLA is more intuitive for humans to read and adjust
  • Background layers stack from top to bottom
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
Typography

CSS typography controls the appearance of text on a web page. The font-family property specifies which typeface to use, with fallback stacks ensuring the browser can find an available font. Generic families like serif, sans-serif, and monospace serve as final fallbacks.

Web fonts can be loaded using the @font-face at-rule, which tells the browser where to download font files. Services like Google Fonts make this process easier by hosting font files and providing ready-to-use CSS snippets. Variable fonts offer multiple weights and styles within a single file.

@font-face { font-family: 'MyCustomFont'; src: url('fonts/custom.woff2') format('woff2'); } body { font-family: 'MyCustomFont', 'Segoe UI', Tahoma, sans-serif; }

Font size can be specified in various units: pixels provide precise control, em units are relative to the parent font size, rem units are relative to the root element, and percentage units scale proportionally. The font-weight property controls boldness, ranging from 100 (thin) to 900 (black), with 400 being normal and 700 being bold.

  • Always provide a fallback font stack
  • Use WOFF2 format for optimal web font performance
  • rem units are preferred for accessibility and scalability
  • Limit the number of custom fonts to reduce page load
Text Styling

Beyond font selection, CSS offers many properties for fine-tuning text appearance. The text-align property controls horizontal alignment, while text-decoration adds underlines, overlines, and strikethroughs. The text-transform property changes letter casing without modifying the HTML content.

Spacing properties dramatically affect readability. line-height controls the space between lines, letter-spacing adjusts the space between characters, and word-spacing affects the gap between words. Proper spacing makes text comfortable to read across different screen sizes.

p { text-align: justify; line-height: 1.8; letter-spacing: 0.02em; text-indent: 2rem; } h2 { text-transform: uppercase; letter-spacing: 0.1em; }

The text-shadow property adds depth to text by applying one or more shadow effects. It accepts offset values, blur radius, and color. Multiple shadows can be stacked by separating them with commas, enabling effects like engraved text, glowing text, or letterpress styles.

  • Use text-decoration for links, not for emphasis
  • text-transform: uppercase avoids retyping HTML
  • white-space controls how whitespace in HTML is handled
  • text-overflow: ellipsis adds an ellipsis to truncated text
text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);
Sizing and Units

CSS provides a rich set of units for specifying lengths, sizes, and distances. Absolute units like px, pt, and cm are fixed and do not scale with the viewport. Pixels are the most common absolute unit for screen-based layouts.

Relative units are more flexible and responsive. The em unit is relative to the parent element's font size, rem is relative to the root font size, percentage is relative to the parent element's same property, and viewport units (vw, vh, vmin, vmax) are relative to the viewport dimensions.

/* Absolute unit */ .box { width: 300px; } /* Relative to parent font size */ .child { padding: 2em; } /* Relative to root font size */ .content { margin: 1.5rem; } /* Viewport-relative */ .hero { height: 100vh; }

The calc() function allows mathematical operations between values of different units, enabling hybrid sizing strategies. For example, you can combine percentages with fixed lengths to create fluid layouts with precise constraints.

  • px for borders and fixed-size elements
  • rem for font sizes and spacing in scalable layouts
  • % for fluid widths within containers
  • vw/vh for full-viewport sections
  • calc() for combining different unit types
width: calc(100% - 40px);
Positioning

CSS positioning controls how elements are placed in the document layout. The position property accepts five values: static (default), relative, absolute, fixed, and sticky. Each value changes how the element is positioned and how it affects surrounding elements.

Static positioning follows the normal document flow. Relative positioning shifts an element relative to its normal position without removing it from the flow. Absolute positioning removes the element from the flow and positions it relative to its nearest positioned ancestor.

.relative-box { position: relative; top: 20px; left: 10px; } .absolute-box { position: absolute; top: 0; right: 0; } .fixed-header { position: fixed; top: 0; width: 100%; }

Fixed positioning anchors an element to the viewport, keeping it visible during scrolling. Sticky positioning is a hybrid that toggles between relative and fixed based on scroll position, making it ideal for section headers that should stick while scrolling through content.

  • Static is the default — no positioning applied
  • Relative keeps the element in the document flow
  • Absolute removes the element from the flow
  • Fixed pins to the viewport regardless of scroll
  • Sticky becomes fixed after reaching a scroll threshold
Transitions

CSS transitions allow property changes to occur smoothly over a specified duration, rather than instantaneously. A transition animates the change from one property value to another when a state change triggers it, such as hovering over an element or adding a class.

The transition shorthand combines four sub-properties: transition-property specifies which properties to animate, transition-duration sets how long the animation takes, transition-timing-function controls the acceleration curve, and transition-delay adds a wait time before the animation starts.

.button { background-color: blue; color: white; transition: background-color 0.3s ease, transform 0.2s ease; } .button:hover { background-color: darkblue; transform: scale(1.05); }

Not all properties can be transitioned. Only properties with interpolatable values — numbers, colors, transforms, and similar — support smooth transitions. Properties like display cannot be transitioned because they have no intermediate state between values.

  • Use ease for natural-looking deceleration
  • Keep durations between 200ms and 500ms for UI elements
  • Transition only opacity and transform for GPU-accelerated performance
  • Respect prefers-reduced-motion for accessibility
Animations

CSS animations provide more control than transitions by allowing multi-step animations with keyframes. The @keyframes at-rule defines the animation sequence by specifying styles at various points along the animation timeline, from 0% (start) to 100% (end).

The animation shorthand combines multiple properties: name, duration, timing function, delay, iteration count, direction, fill mode, and play state. Animations can run once, loop infinitely, play in reverse, or alternate between forward and reverse on successive iterations.

@keyframes fadeIn { from { opacity: 0; transform: translateY(20px); } to { opacity: 1; transform: translateY(0); } } .element { animation: fadeIn 1s ease-out forwards; }

Animation events like animationstart, animationend, and animationiteration can be detected for coordinating JavaScript behavior, but all animation logic itself can be implemented entirely in CSS. Combining multiple animations on the same element is possible by comma-separating the animation values.

  • Use from and to for simple two-state animations
  • Use percentage keyframes for multi-step sequences
  • animation-fill-mode: forwards retains the end state
  • infinite loops the animation indefinitely
  • Test animation impact with prefers-reduced-motion
Media Queries

Media queries are a cornerstone of responsive web design. They allow CSS rules to be applied conditionally based on characteristics of the user's device, such as screen width, height, orientation, resolution, or even user preferences like color scheme.

The @media at-rule takes a media type (screen, print, speech) and one or more feature expressions. When the conditions are met, the enclosed styles override or supplement the default styles. This enables the same HTML to adapt to phones, tablets, laptops, and desktops without changes.

/* Mobile first: base styles */ .container { display: block; } /* Tablet and above */ @media (min-width: 768px) { .container { display: grid; grid-template-columns: 1fr 1fr; } } /* Desktop and above */ @media (min-width: 1024px) { .container { grid-template-columns: 1fr 1fr 1fr; } }

Modern media queries also support features like prefers-color-scheme for dark mode, prefers-reduced-motion for accessibility, prefers-contrast for high contrast needs, and hover for detecting touch devices. These features help create inclusive designs that adapt to user preferences.

  • Use mobile-first approach: base styles for mobile, then enhance upward
  • Common breakpoints: 768px (tablet), 1024px (laptop), 1440px (desktop)
  • Test actual content, not just device widths
  • Combine media queries with logical operators (and, not, only)
