Introduction

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML.

CSS describes how elements should be rendered on screen, on paper, in speech, or on other media.

CSS Selectors

Selectors are patterns used to select the HTML elements you want to style.

There are many types of selectors, each with different specificity and use cases.

h1 { color: blue; }
  • Type selectors (e.g., h1, p, div)
  • Class selectors (e.g., .my-class)
  • ID selectors (e.g., #my-id)
Box Model

The CSS box model is a fundamental concept that describes how elements are structured.

Every element is composed of content, padding, border, and margin areas.

Understanding the box model is essential for creating layouts.

box-sizing: border-box; margin: 10px 15px;
Flexbox

Flexbox is a one-dimensional layout method for arranging items in rows or columns.

It provides powerful alignment and distribution capabilities.

display: flex;
  • justify-content controls horizontal alignment
  • align-items controls vertical alignment
Grid Layout

CSS Grid Layout is a two-dimensional layout system for the web.

Grid allows you to create complex layouts with rows and columns.

display: grid; grid-template-columns: 1fr 1fr;
  • Grid is ideal for page-level layouts
